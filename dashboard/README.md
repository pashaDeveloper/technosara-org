# داشبورد تکنوسرا

این پوشه داشبورد React متصل به سرور Express پوشهٔ `server` است.

تمام صفحات، منوها، نمودارها، کامپوننت‌ها و دارایی‌های داشبورد اصلی `nab/dashboard` در این نسخه کپی شده‌اند. صفحهٔ اصلی شامل همان ۹ کارت آمار و نمودار است؛ اعداد و داده‌های نمونهٔ قالب به آمار واقعی سرور متصل نشده‌اند. ورود، ثبت‌نام، کوکی امن و تنظیمات پراکسی تکنوسرا حفظ شده‌اند.

زبان فرم‌ها فارسی است؛ انتخاب زبان، ترجمهٔ خودکار و الزام تکمیل ترجمه‌های انگلیسی، ترکی و عربی غیرفعال شده‌اند. خواندن ساختار دادهٔ قدیمی ترجمه‌ها برای سازگاری صفحات با پاسخ API حفظ شده است. صفحات تجاری کپی شده‌اند و اجرای عملیات آن‌ها به وجود API متناظر در سرور تکنوسرا بستگی دارد؛ در این انتقال سرور تغییر نکرده است.

نسخهٔ پیش از ادغام در پوشهٔ مجاور `dashboard-before-full-copy-20260917-134616` نگهداری شده است.

## اجرای توسعه

MongoDB و سپس سرور را اجرا کنید:

```powershell
cd server
npm.cmd install
npm.cmd run dev
```

در ترمینال دیگری از ریشهٔ پروژه:

```powershell
cd dashboard
npm.cmd install
npm.cmd run dev
```

داشبورد در `http://localhost:3001` باز می‌شود. درخواست‌های `/api` به سرور
`http://127.0.0.1:8080` ارسال می‌شوند. برای تغییر آدرس سرور، `.env.example`
را به `.env` کپی کنید و `API_BASE` را تغییر دهید.

اگر حسابی وجود ندارد، در صفحهٔ ورود «ساخت مدیر کل» را بزنید. پس از آن فقط
مدیر کل از داخل داشبورد می‌تواند مدیر جدید بسازد. طبق سیاست فعلی سرور، مدیر
جدید غیرفعال است تا تأیید شود. ورود و خروج از کوکی HttpOnly استفاده می‌کنند.
تصویر پروفایل از میان ۱۰۰ آواتار آماده یا از طریق آدرس URL اختیاری ثبت می‌شود؛ API فعلی آپلود فایل ندارد.

## نسخهٔ نهایی و بررسی

در `dashboard` دستور `npm.cmd run build` و سپس در `server` دستور
`npm.cmd start` را اجرا کنید. Express فایل‌های `dashboard/dist` و API را
روی پورت 8080 ارائه می‌کند. برای بررسی اتصال پراکسی، `npm.cmd test` را در
پوشهٔ `dashboard` اجرا کنید.

تست مرورگری محلی (پس از build) در PowerShell:

```powershell
$env:DASHBOARD_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
node test/browser-smoke.mjs
```
