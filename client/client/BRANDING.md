# Technosara links

Public brand settings and social links are in `src/config/brand.js`.
Social URLs currently use the requested `technosara` handle; account ownership has not been verified.

The primary public URL is `https://technosara.com`. `NEXT_PUBLIC_SITE_URL` can override it in the deployment environment or `.env.local`. This controls Open Graph URLs, Twitter image URLs and `/sitemap.xml`.

The original template author comments and internal API module names are retained as source provenance and implementation identifiers.
